# Сайт Вікторії Загороднюк

Односторінковий статичний сайт (АСТОН Україна, корпоративне медичне страхування).

- `index.html` — сторінка. Усі дані для заміни (посада, телефон, пошта, LinkedIn, Calendly, фото, адреса офісу) зібрані в блоці `SITE_CONFIG` на початку файлу.
- `img/` — фото, логотип АСТОН (світла й темна версії), значок вкладки.

## Публікація на GitHub Pages
1. Створіть на github.com новий публічний репозиторій, наприклад `viktoriia-zagorodniuk`.
2. Натисніть «uploading an existing file» і перетягніть усі файли з цієї теки (разом із текою `img`).
3. Settings → Pages → Source: «Deploy from a branch», гілка `main`, тека `/ (root)` → Save.
4. За 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/viktoriia-zagorodniuk/`.
